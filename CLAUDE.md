# Instruções do projeto

## Commits
- Mensagem no padrão `vDDMMHHMM`, com data/hora de Brasília (ex.: `v01101406` = 01/10 às 14:06). Sem corpo.

## Pull requests
- Título e descrição em português, curtos e diretos, no tom de quem fez a alteração.

## Projeto
- React + Vite + Tailwind, dados no Firebase (`id-liquidacao`). Rodar `npm run build` e `npm run lint` antes de enviar.
